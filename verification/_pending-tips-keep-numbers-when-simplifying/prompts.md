# 検証手順 ― Tips「やさしくすると崩れる数字を、指示の一言で防げるか」（仮）

2-③（2026-09-21 公開予定）の未検証の追試。**このフォルダは投稿ファイル名が決まっていないので `_pending-` で切っている。**
記事の日付が決まったら `YYYY-MM-DD-<slug>` に改名すること。

## 狙い

2-③ で、読む人を「幼稚園児」「小学生」に指定した出力では、論文の数字が崩れた。

- 幼稚園児向け: 論文の「2〜3割」を「2〜3人に1人」と書いた（正しくは10人に2〜3人）
- 小学生向け: 論文の「増えた38%・減った29%」を「同じくらい」と書いた

指示に「数字は元の表記のまま残してください」と足せば、崩れなくなるかを試す。

## 先に押さえること（比べる意味があるかの確認）

2-③ の出力は各レベル**1回だけ**だった。崩れが、指示の問題ではなく1回の出力の揺れだった可能性がある。
だから、**まず「元の指示」を複数回投げて、崩れが再現するか**を見る。再現しなければ、追加の一言の効果は比べられない。

## 条件

- 素材: GLOCOM Discussion Paper 24-001（全21ページ）
  https://www.glocom.ac.jp/wp-content/uploads/2024/04/GLOCOM_DISCUSSIONPAPER_No.24_2024-001-1.pdf
- ツール: Claude Sonnet 5（2-③ と揃える。ほかのツールは今回は見ない）
- **各回とも新規チャット**でPDFを添付して投げる。実施日とモデル名を記録する
- 読む人: 幼稚園児・小学生の2つだけ（崩れたのがこの2つ）

## 投げる指示

A（元の指示）

```
添付のPDFの内容を、【幼稚園児】でもわかるように説明してください。
```

B（数字の指示を足す）

```
添付のPDFの内容を、【幼稚園児】でもわかるように説明してください。
数字は、元の論文の表記のまま残してください。
```

【 】を「幼稚園児」「小学生」に替える。

## 回数（案）

| | 幼稚園児 | 小学生 |
|---|---|---|
| A（元の指示） | 3回 | 3回 |
| B（数字の指示を足す） | 3回 | 3回 |

計12回。多ければ各2回まで減らしてよいが、**Aで崩れが出るかを見るのが先**なので、Aの回数は減らさない。
出力は `pdf-kids-{kindergarten,elementary}-{a,b}-{1,2,3}.md` のように保存する。

## 数字の確かめ方

論文の値は次のとおり（2-③ の照合で確認済み）。出力の該当箇所と見比べる。

| 見る場所 | 論文の値 | 2-③ で崩れた書き方 |
|---|---|---|
| どれだけ加工しても著作権を認めない人 | 2〜3割（10人に2〜3人） | 「2〜3人に1人」（幼稚園児向け） |
| 手で描く絵の増減 | 増えた38%・減った29% | 「同じくらい」（小学生向け） |
| AIを使っている人 | 27%（約4分の1） | 幼稚園児向けでは「4人に1人」で正しかった |
| 無断学習を問題視 | 約6割、問題ないとする人は約3割 | 幼稚園児向けでは「10人中6人／3人」で正しかった |

崩れ方が違っても、**数字が論文と食い違えば記録する**。「正確に写せたか」だけでなく、
「数字を出さずに逃げた（数字が消えた）」も別に記録する。数字が消えるのは、崩れとは別の外れ方。

## 記録すること

- 実施日 / モデル名:
- A で崩れは再現したか（回ごと、どの数字が、どう崩れたか）:
- B で崩れは減ったか。数字が消えていないか。ほかの箇所に副作用が出ていないか:
- 「元の表記のまま」を守った結果、読みやすさはどう変わったか（幼稚園児向けに「27%」「2〜3割」が残ると分かりにくくなるか）:
- 想定外だったこと:

## 記事に使うときの注意

- 結果が仮説どおり（防げた）でなくても、そのまま書く。「防げなかった」「数字が消えた」は Tips として価値がある
- 回数が少ない（各3回）ことと、Claude だけであることを、記事に書く
- 論文は公開資料だが利用条件の記載が見当たらない。要約と短い引用にとどめ、出典リンクを付ける
