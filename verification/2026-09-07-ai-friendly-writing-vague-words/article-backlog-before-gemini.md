### 構成・ローテーション原則

- 基礎シリーズ（1. きほん）は連続させず、業務Tips系と交互に配置する。

- 随時枠（Tips・小技 / ニュース）で埋める週は、公開順テーブルをずらさず対応する。
- 今後、記事末尾で具体的な「次回予告」を行うと順序が固定化するため避ける。

## 4. シリーズ企画一覧

**1. 生成AIのきほん（全9回）**
1. セキュリティ設定を見直そう
2. ハルシネーションとは何か、なぜ起こるのか
3. AIは「持っている知識」しか扱えない（7-①, 9-②へ誘導）
4. AIに「このモデルの使い方」を聞いてみよう
5. プランモードって何？「モード」の違いを理解する
6. AIが扱えるファイル・形式を聞いてみよう
7. AIツールの便利機能、こんな時に使おう
8. コンテキストが溢れるとどうなる？AIの「物忘れ」「混乱」現象
9. 現場でAIが使えないときに、今やっておくこと（L0読者向け準備）

**2. プロンプトの基礎体力（全2回）**
1. 文章を構造化して書く基本（PREP法・文章表現）
2. プロンプトの書き方の基本（Markdown記法）

**3. プロンプト設計の型（全5回）**
1. 要約（著作権切れ小説を使用）
2. 企画書化
3. 添削
4. 壁打ち
5. 役割設定
*(候補: 重み付けによる異色出力の抽出)*

**4. AIにキャラクターを与えてみよう（全2回）**
1. ペルソナ設定でAIの個性・モノマネ力を引き出す
2. 口調変換デモ（ヴィラン風・ギャル風・キャラ風）

**5. プロンプト設計（ステップアップ編）（全4回）**
1. AIにプロンプト自体を書かせる方法
2. 複数ステップの作業を実行させる方法
3. 矛盾内容を上位モデルにレビュー・修正させる方法
4. 自分だけのエージェントとして保存・呼び出す（9-②へ誘導）

**6. 業務別活用事例（棚卸し1本 + 全5回 + テンプレート2回）**
- **⓪ 業務棚卸し（標準型）**: 判定軸と実践（筆者の実物リスト添付）
1. 議事録 / 2. メール / 3. 資料作成 / 4. データ集計 / 5. 企画立案
- **テンプレート活用**:
  1. 業務別テンプレート集
  2. 上手なテンプレートの条件（疑問文指定、分量目安など）

**7. ツール使い分け（全6回）**
1. ノートブック機能でナレッジ構築（簡易RAG）
2. 「社外に出せない」現場のためのAI選び（制約型ベース）
3. 長文要約の強さ比較（上限・入力方式）
4. コードレビュー向きツール比較（指摘精度・誤検知）
5. Excel・表データ処理（入出力と添付禁止環境での手順）
6. 無料プラン比較（検証時期を明確化）

**8. AIの拡張のしくみ（概念編・全4回）**
1. AIの「指示の与え方」整理（知識付与と機能拡張の概念整理）
2. Anthropic公式Skills解説
3. MCP（Model Context Protocol）概論
4. MCP運用上の注意点（トークン消費対策）

**9. 自分のツール・エージェントを作ってみよう（ハンズオン・全2回）**
1. 簡易ツールの作成（天気予報取得など）
2. 簡易エージェントの作成（ツール＋AI連携）

**10. 開発者としてのAI活用ノウハウ（実践編・全4回）**
1. セキュリティ第2弾：与えてはいけない情報（認証・DB接続情報）
2. コンテキスト長を踏まえた設計方法論
3. AIが得意な開発言語（型付き言語の優位性）
4. 確率論と決定論の使い分け

**11. 現場導入・推進（マネジメント編・全2回）**
1. 現場の生成AI導入レベル診断
2. 現場導入のアピール術

**12. ニュース枠**（随時更新）
