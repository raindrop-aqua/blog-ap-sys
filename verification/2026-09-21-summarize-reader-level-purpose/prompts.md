# 検証手順 ― 記事 2-③「要約して」に足す一言（読む人と目的を渡す）

9/7 の記事（2-① AIにわかりやすい文章を書く基本）の延長として、「要約して」という丸投げ語に何を足すと出力が変わるかを検証した。
2-① では「判断を自分で決めて渡す」「聞き返させる」を試した。ここでは**目的**と**読む人**を渡してみる。

素材と条件は下記のとおり。同じPDF・同じツール／モデルで新規チャット。

## ステップ1: PDF要約の投げ方を変えて比べる（Before / After）

素材: GLOCOM Discussion Paper 24-001（2024年4月）
　「画像生成AIについてのクリエイターの賛否は割れている」田中辰雄ほか、全21ページ
　https://www.glocom.ac.jp/wp-content/uploads/2024/04/GLOCOM_DISCUSSIONPAPER_No.24_2024-001-1.pdf
　- 一般公開されており読者も入手できる。常駐先の資料ではない
　- アンケート調査の報告で、図表・統計が多い。5章立て＋小節あり
　- この論文はp2に著者自身の「要約」と「目次」を載せている（素の「要約して」が要旨をなぞるだけになるかを見る狙いがあった。結果は下記のとおりそうならなかった）
条件: 同じPDF・同じツール／モデル・新規チャット。

### Before（いつもの投げ方）

```
添付のPDFを要約してください。
```

### After（構造化＋目的を足す）

```
添付のPDFについて、次の3つを出してください。
1. 章ごとに1行の要約（表形式）
2. この文書で筆者が最も伝えたい主張トップ3
3. この文書を実務で使うために、私が確認・検討すべき論点を5つ（質問の形で）
```

### 記録すること

- 実施日: 2026-09-09(水)
- ツール・モデル: ChatGPT（不明）／Claude sonnet 5／Gemini 3.6 Flash／Copilot（不明）
- 出力: `pdf-summary-{before,after}-{chatgpt,claude,gemini,copilot}.md`（8本）

#### 筆者の主観

- 筆者の言葉（原文どおり）:「before のほうが分かりやすい（ディティールを削っているから当たり前だけど）」
  → 「After のほうが情報量が多いから、Before が分かりやすいのは当たり前」の意味（筆者確認済み）。
- 別仮説（筆者）:「小学生/中学生/高校生でも分かりやすいようにまとめて、というのはどうか。年齢が上がっていくほど After に近づくと思う」

#### 8本を読んだ分析（アシスタント）

**Before（素の「要約して」）**

- 4本とも p2 の要旨をなぞるだけでは終わらず、数字（利用27%／無断学習6割問題視／ハードライナー2〜3割）や
  下位の発見（コミケ参加者は熱心な利用者かつ批判者／プロアマ差なし／女性は否定寄り／出力枚数と評価の逆転）まで拾った。
  → 「要旨のコピペ」問題は出なかった。むしろ逆。
- 問題は別のところ。**全部が同じ重みで並ぶ「盛り合わせ」**になっている。
  特に ChatGPT の Before は8セクション＋表で長大。読み終えても「で、何が幹なのか」が残らない。
  Copilot は絵文字見出しで装飾過多、これも幹が見えにくい。
  → 筆者の「要約を読んでも全体が掴めない」は、要約が短すぎるからでも間違っているからでもなく、
  　**優先順位がついていない・形がない**から。長くすると余計に掴めなくなる。
- Before はどれも「この情報をどう使うか」が無い。純粋な内容の写し。

**After（章ごと表 ＋ 主張トップ3 ＋ 論点を質問で5つ）**

- **章ごと1行の表**: 4本とも5行のきれいな表。Before に無かった「持てる形」がこれで出た。
- **主張トップ3**: 4本が同じ3点に収束（①賛否は拮抗・多数派なし ②利用の半分は非公開のヒント用途 ③過渡期なので拙速な規制は避けよ）。
  ツールをまたいで一致 → この3点は信頼してよい、と読者に言える。
- **論点を質問で5つ**: ここが本命。「質問が思いつかない」に直接効く。しかも出てきた質問が非自明:
  - Claude: サンプルの代表性／「著作権を認める」は法解釈でなく世論である点／相関と因果の逆転／
    出力枚数と評価の矛盾をどう扱うか／2023年時点の調査で陳腐化していないか
    → **研究の読み方を疑う**方向の問い。
  - ChatGPT・Gemini: 用途区分／加工基準の社内ルール／学習データの受容性／レピュテーションリスク／暫定ルール＋定期見直し
    → **自社の方針に落とす**方向の問い。
  - Copilot: 論文のテーマを質問文に言い換えた程度で、新しい角度は弱め。
- ★発見: 「論点を出させる」と、ツールによって出る方向が違う（Claude＝方法論の吟味／ChatGPT・Gemini＝実務適用）。
  片方だけだと視野が狭くなる。**2ツールに投げて突き合わせる**と穴が減る。


**記事の骨として使える線**

1. 素の「要約して」は、全部が同じ重みで並ぶ盛り合わせになりやすい（ChatGPT・Copilot の Before が実例）。長さは掴みやすさと無関係。
2. 「章ごと1行の表」で形が出る。「主張トップ3」で幹が出る（4ツール一致で裏も取れる）。
3. 「私が確認すべき論点を質問で5つ」で"質問が思いつかない"が解ける。出た問いは自力では出しにくいもの。

## ステップ2: 読む人のレベルを指定して比べる（幼稚園児〜大学生）

狙い: これも「目的・状況を渡す」ことの一例として検証する。今回渡す状況は「誰に説明したいか」。
情報量の「つまみ」として効くか（掴みやすさと情報量のトレードオフを、指示1行で動かせるか）を見る。
仮説（筆者）: 年齢を上げるほど、出力はステップ1の After に近づく。いちばん見たいのは小学生。

素材: ステップ1と同じ GLOCOM Discussion Paper 24-001。
条件: 同じPDF・新規チャット。**実際の実施は Claude sonnet 5 のみ・各レベル1回**（当初予定の2ツール突き合わせはしていない）。
　筆者の判断で対象を拡張し、幼稚園児〜大学生の5段階で実施（2026-09-19までに実施）。

### 投げる指示（レベルだけ差し替え）

```
添付のPDFの内容を、小学生でもわかるように説明してください。
```

```
添付のPDFの内容を、中学生でもわかるように説明してください。
```

```
添付のPDFの内容を、高校生でもわかるように説明してください。
```

実際に投げたレベルは5つ（幼稚園児・小学生・中学生・高校生・大学生）。指示文の型は上と同じ。

出力: `pdf-summary-kids-{kindergarten-children,elementary,junior-high-school,high-school,university}-claude.md`

### 記録すること

- 実施日 / ツール・モデル: 2026-09-19までに実施 / Claude sonnet 5（1ツール・各1回）
- 筆者の主観（2026-09-19）: **幼稚園児版と小学生版がいちばん分かりやすかった**（疲れた頭で「掴む」用途）。
  「before のほうが分かりやすい（ディティールを削っているから当たり前）」は
  「After のほうが情報量が多いから、Before が分かりやすいのは当たり前」の意味で合っている（筆者確認済み）。
  → 掴みやすさは情報量とのトレードオフ。読者レベルの指定は、その情報量を指示1行で動かすつまみとして効いた。

#### 5本を読んだ分析（アシスタント）

| レベル | 構成 | 数字 | 用語の扱い | 注意・限界の欄 |
|---|---|---|---|---|
| 幼稚園児 | どんなお話→わかったこと5→この本の人の考え | 「4人に1人」「10人中6人」（%は出ない） | AIを「コンピューターのふしぎな先生」 | 「ご注意」が短く付く |
| 小学生 | 何をした→わかったこと6→結論 | 27%、約6割、2〜3割 | 猫が空を飛ぶ例、著作権を1文 | 「分からないこと・気をつけたいこと」3点 |
| 中学生 | 資料は何→言葉→わかったこと5→結論 | 38%/29%、5〜6割、4〜5割など増える | 用語ミニ辞書3つ（AI・著作権・コミケ） | 「読むときの注意」3点 |
| 高校生 | どんな研究→わかったこと5→結論 | 46%、+10ポイントなどさらに増える | 著作権を1文 | 「読むときの注意点」5点（設問の作りによる偏りを含む） |
| 大学生 | 問い・方法→主な結果5→結論 | 64%など | 統計用語3つ（ロジット回帰・限界効果・有意） | 「読むときの注意点」4点（代表性・因果・探索的・陳腐化） |

観察（この1ツール・各1回の範囲で言えること）:

1. **幹は全レベルで同じだった。** 「使う人は約4人に1人」「使い方の半分は世に出さないヒント用途」
   「加工が大きいほど著作権を認める人が増えるが2〜3割は認めない」「無断学習は約6割が問題視」
   「賛否は割れていて過渡期」— 幼稚園児版にも同じ5本柱が残った。
   変わるのは**解像度**（数字の有無・用語解説・注意の量）で、何が重要かの**選別**は動かない。
   → ステップ1のトップ3とも重なる。指示に「誰向けか」を1行足すだけで、Beforeに無かった取捨選択が出た。
2. **筆者仮説「年齢が上がるほど After に近づく」は、部分的に成り立った。**
   近づいたのは「章ごとの表」ではなく「読むときの注意」（幼稚園児は簡易→小3→中3→高5→大4）。
   高校生・大学生版の注意の中身は、Claude の After の「論点」（サンプルの代表性・相関と因果・調査時点の古さ）と重なる。
   章ごとの表は全レベルで出なかった。
3. **頼んでいない「注意・限界」が全レベルに出た**（幼稚園児にも）。
   これは今回の Claude sonnet 5 の癖の可能性がある。他ツールでは確認していないので一般化しない。
4. **平易化の副作用**（幼稚園児版）:
   論文を「この本」と言い換えている／「女の人のほうがAIにきびしい理由は分からない」という注意だけが残り、
   本文にその話が無いため子どもには文脈が通らない。単純化しすぎのチェック観点として使える。
5. 大学生版だけ「今は2026年です」と現在時点を踏まえて陳腐化を指摘した（他レベルは「その後かなり動いているはず」程度）。

#### 出力の数字を論文と照合した結果（アシスタント、2026-09-19）

論文PDF（21ページ）のテキストと突き合わせた。

**一致を確認できたもの**: 27%（12%＋9%＋6%）／46%（「使ったことはないが、AIによる絵を見たことはある」）／
64%（63.8%「短い時間で多数の作品が作れるようになった」）／手描き 増38%・減29%／
無断学習 約6割が問題視・約3割が問題なし（Aに近い＋どちらかといえばA ＝ 利用者68.5%・非利用者57.3%、B側 27.6%・33.8%）／
大きな加工で著作権を認める 5〜6割（57.7%・60.4%）／認めない 2〜3割（別作品の設問で32.3%・27.9%）／
「探索的研究」（論文の記述）／設問Bが「ほぼ無罪放免」なので深刻さまでは測れない（論文の記述。高校生・大学生版の指摘は正しい）／
女性の否定的傾向は「理由は不明」（論文の記述）。

**食い違いを見つけたもの**（どちらも「平易化の副作用」の実例）:

1. **幼稚園児版の「2〜3人に1人」は誤変換。** 論文は「2〜3割」。10人に2〜3人であって、2〜3人に1人（＝33〜50%）ではない。
   同じ幼稚園児版の「4人に1人」（27%）と「10人中6人／3人」は正しく直っており、この1か所だけが崩れた。
2. **小学生版は手描きの増減を「同じくらい」に丸めた。** 論文は増えた38%・減った29%。中学生以上は38%・29%と正確に書いている。

**照合していないもの**: 「4〜5割」（肯定・否定の賛同率）、「約10ポイント」（利用者のほうが肯定的）。論文の図表の値からはすぐに確認できなかったため、
インフォグラフィックには載せていない。
