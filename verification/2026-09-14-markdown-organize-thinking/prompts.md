# 検証手順

題材: 私物のヘッドホン選び（常駐先の情報は一切含まない。読者がそのまま追試できる）
条件: **各ステップを別々の新規チャット**で投げる。ChatGPT と Claude の2ツール。
3ステップ: 雑に投げる → 箇条書きにする（AIが要求の矛盾を指摘） → 矛盾を解消して投げ直す。

---

## Before（雑に投げる）

```
ヘッドホンのおすすめ教えて
```

### Before の派生（Claude が聞き返してきた場合）

- `headphones-before-claude.md` … 聞き返しに会話で答えたバージョン（後出しで条件が5つ出た）
- `headphones-before-claude-declined.md` … 聞き返しに答えず「特にこだわりはない」で促したバージョン

## After（箇条書きで頭の中を出す）

音漏れ（プライベートに聴きたい）と耳の熱さが両立しない、という矛盾を残したまま投げる。

```
* デスクワーク中に集中するためにBGMとして音楽を聴きたい
* スピーカーはあるけど、家族もいるのでもう少しプライベートに聴きたい
* ヘッドホンをずっと耳につけていると耳が熱くなって不快
* メガネをかけているのであんまり圧迫するものは耳が痛くなる
```

---

## After②（矛盾を解消して投げ直す）

音漏れ（プライベートに聴きたい）を外し、装着感を最優先に倒した。ネックバンド型・オープンイヤーも候補に含める。

```
デスクワーク中に集中するためのヘッドホン、またはそれに代わるものを探しています。
音漏れは気にしません。装着感を最優先にしたいです。

* 長時間つけていても耳が熱くなりにくいこと
* メガネなので、締め付けの強いものは避けたい
* 仕事中のBGM用途で、音質は二の次
* ヘッドホンにこだわらない。ネックバンド型（肩掛け）やオープンイヤーも候補に入れてほしい
```

- `headphones-after2-chatgpt.md`
- `headphones-after2-claude.md`

# 記録

- 使ったツール: ChatGPT ／ Claude（いずれもモデル未特定。Claude は候補をカルーセルUIで表示）
- 実施日: 2026年9月6日

## Before（雑版）で返ってきたもの
- ChatGPT: Sony WH-1000XM6 / Bose QC Ultra / AirPods Max の定番3機種。5〜6万円台のプレミアムなオーバーイヤー。末尾で予算と用途を質問
- Claude（declined）: 聞き返し→「特にこだわりはない」で促すと、Sony WH-1000XM6 / Bose / Sennheiser の定番3機種。末尾で予算・有線希望を質問
- Claude（answered）: 聞き返しに会話で回答。そのとき「会議用途」「骨伝導可」「ネックスピーカー可」「予算1〜3万」が後出しで出た → OpenComm2 / OpenFit2 を提案
- 条件（メガネ／耳の熱／家族）を踏まえた提案になっていたか: 雑版はいずれもNo。両ツールともほぼ同じ定番3機種に収束した
- 聞き返してきたか: ChatGPT=答えてから質問 / Claude=先に質問

## After（箇条書き版）で返ってきたもの
- ChatGPT: 回答カテゴリが変化。「密閉型より耳をふさがないオープンイヤー型を第一候補に」→ Shokz OpenFit 2 を筆頭、Bose・Sony も残す。耳の蒸れ／メガネ相性／音漏れの少なさ／集中力を4段階採点した表を自作
- Claude: 同じく耳たぶに挟むイヤーカフ型へ（OpenDots ONE / LinkBuds Clip / AeroClip）。音漏れは小さめだが完全な遮音ではない、と但し書き
- 雑版と何が変わったか: 定番プレミアム → 耳を覆わない型。条件ひとつずつに対応した回答になった

## 箇条書きにして見えた矛盾（頭の整理の効果）
- ChatGPT の採点表で、「耳の蒸れ」に強いオープンイヤー型は「音漏れの少なさ」が最低、逆にオーバーイヤー型は「耳の蒸れ」が最低。「快適性だけならOpenFit 2を先に試したい」と書いてきた
- 「家族がいるからプライベートに（＝音漏れ抑えたい＝密閉）」と「耳が熱いのが嫌（＝覆わない）」が逆方向。**筆者は並べておらず、自分では気づかなかった。ChatGPTが表で突きつけてきた**

## After②（矛盾を解消して投げ直し）で返ってきたもの
- 音漏れを捨て、装着感最優先、ネックバンド型・オープンイヤー可、で投げ直し
- ChatGPT: Shokz OpenFit 2+ を筆頭に、Sony LinkBuds Open、そして**ネックバンドスピーカー（SRS-NB10）**を有力候補に。「『音漏れは気にしません』という条件があるので、普通なら候補から外れるネックバンドスピーカーが一気に有力になります」
- Claude: 骨伝導（Shokz OpenRun Pro）を筆頭に、イヤーフック型、ネックスピーカー。「音漏れを気にしないとのことなので、候補として十分検討に値します」
- 変わったこと: 音漏れ条件を外した瞬間、ネックバンドスピーカー・骨伝導という新カテゴリが候補に入った。条件を外すと決めたのは筆者、AIはその後の地図を出しただけ

## 想定外だったこと
- 雑版だと、聞き返す Claude と即答する ChatGPT で入口の体験は違うのに、条件を渡さなければ着地はほぼ同じ定番3機種だった
- 矛盾に気づいたのは自分ではなく AI。ただし箇条書きにしていなければ AI も並べて見せられなかった
- 条件をひとつ外すだけで候補カテゴリが増える（減るのではなく）
