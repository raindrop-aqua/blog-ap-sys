## psqlでの確認（2026-10-08、arm64v8/postgres:17.5 コンテナの psql 17.5。サーバーには接続していない）

```
$ psql -h localhost -p 5432 -U app_user -d sampledb --password='secret'
psql: option '--password' doesn't allow an argument
psql: hint: Try "psql --help" for more information.
（exit=1）

$ psql -h localhost -p 5432 -U app_user -d sampledb "?sslmode=prefer"
psql: warning: extra command-line argument "?sslmode=prefer" ignored
（このあと接続を試みる。sslmodeの指定は効かない）
```

- ChatGPT（03）: 「パスワードを含める」をオンにすると、動かないコマンドが出る
- Gemini（03）: 警告が出るだけで接続に進むので、見落とすとSSLモードが効いていないことに気づけない
