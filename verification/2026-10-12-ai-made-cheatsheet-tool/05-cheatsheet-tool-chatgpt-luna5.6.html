PostgreSQL / psql 保守用チートシート

1. psqlへの接続

基本形

psql -h localhost -p 5432 -U postgres -d mydb
接続文字列の可変部分だけを編集できます。下の該当コマンドにも自動反映されます。

例：

psql -h localhost -p 5432 -U postgres -d mydb

ローカル接続

psql -U postgres

環境によっては、

psql

だけで接続できる場合もある。

主なオプション

| オプション | 意味 |

| ----- | ---------------------- |

| -h | PostgreSQLサーバーのホスト名/IP |

| -p | ポート番号（通常 5432） |

| -U | PostgreSQLユーザー |

| -d | データベース名 |

| -f | SQLファイルを実行 |

---

2. 接続直後に確認すること

現在の接続情報

\conninfo

接続先DB、ユーザー、ホスト、ポートなどを確認できる。

本番DBで作業する前には必ず確認する。

---

PostgreSQLのバージョン

SELECT version();

またはシェルから：

psql --version

---

現在のユーザー

SELECT current_user;

現在のデータベース

SELECT current_database();

現在日時

SELECT now();

---

データベース一覧

\list

---

\c データベース名

例：

\c mydb

4. スキーマ・テーブル確認

スキーマ一覧

\dn

---

テーブル一覧

\dt

特定スキーマ：

\dt public.*

\dt *.*

※ 大規模DBでは大量に表示される場合がある。

5. テーブル定義の確認

基本

例：

\d users

---

詳細情報

インデックスなどの詳細も確認できる。

---

6. SQLの基本

SELECT

SELECT * FROM users;

---

件数確認

SELECT COUNT(*) FROM users;

---

上位10件

SELECT *
FROM users
LIMIT 10;

---

条件指定

SELECT *
FROM users
WHERE id = 100;

---

複数条件

SELECT *
FROM users
WHERE id > 100
  AND status = 'active';

---

並び替え

SELECT *
FROM users
ORDER BY id DESC;

---

7. SQL入力時の注意

SQLは通常、最後に ; を付けて実行する。

SELECT *
FROM users
WHERE id = 100;

文字列：

'Taro'

テーブル名・カラム名などの識別子：

"users"

' と " を混同しない。

---

8. SQL入力をキャンセル

入力途中のSQLをキャンセル：

\cancel

---

9. 表示を見やすくする

縦表示

\x

例えば、

SELECT *
FROM users
WHERE id = 1;

通常の横表示ではなく、

-[ RECORD 1 ]-----
id    | 1
name  | Taro
email | taro@example.com

のように表示できる。

もう一度、

\x

で元に戻る。

---

10. SQL実行時間を確認

有効化：

\timing on

例：

SELECT COUNT(*) FROM users;

実行結果に、

Time: 12.345 ms

のように実行時間が表示される。

無効化：

\timing off

---

11. SQLファイルを実行

psql内から

\i update.sql

---

シェルから

psql -h localhost -U postgres -d mydb -f update.sql

---

12. トランザクション

データ変更を伴う保守作業では重要。

開始

BEGIN;

変更

UPDATE users
SET name = 'Taro'
WHERE id = 100;

結果確認

SELECT *
FROM users
WHERE id = 100;

問題なければ確定

COMMIT;

問題があれば取り消し

ROLLBACK;

基本パターン

BEGIN;
  ↓
UPDATE / DELETE
  ↓
SELECTで結果確認
  ↓
問題なし → COMMIT;
問題あり → ROLLBACK;

本番DBでUPDATE/DELETEする場合は、トランザクションを意識する。

19. 保守作業の基本フロー

① 接続

psql -h localhost -p 5432 -U postgres -d mydb

② 接続先確認

\conninfo

③ DB・スキーマ確認

\l
\dn

④ テーブル確認

\dt

⑤ テーブル構造確認

\d テーブル名

⑥ 必要なデータをSELECT

SELECT *
FROM テーブル名
LIMIT 10;

⑦ データ変更が必要ならトランザクション

BEGIN;

⑧ UPDATE / DELETE

UPDATE ...;

または

DELETE ...;

⑨ 結果確認

SELECT ...;

⑩ 問題なければ確定

COMMIT;

問題があれば：

ROLLBACK;

⑪ 終了

\q

20. 本番DBでの注意事項

最初に必ず接続先を確認

\conninfo

特に、

  • 本番
  • ステージング
  • 開発
  • ローカル

を間違えない。

---

UPDATE / DELETE の前にSELECT

例えば、

SELECT *
FROM users
WHERE id = 100;

で対象を確認してから、

UPDATE users
SET status = 'inactive'
WHERE id = 100;

とする。

---

WHERE句を確認

危険：

DELETE FROM users;

これはテーブルの全レコードを削除する。

危険：

UPDATE users
SET status = 'inactive';

これは全レコードを更新する。

基本的には、

DELETE FROM users
WHERE id = 100;
UPDATE users
SET status = 'inactive'
WHERE id = 100;

のように対象を限定する。

---

可能ならトランザクションを使用

BEGIN;

UPDATE users
SET status = 'inactive'
WHERE id = 100;

SELECT *
FROM users
WHERE id = 100;

-- 問題なければ
COMMIT;

-- 問題があれば
-- ROLLBACK;

---

21. 最低限これだけ覚える

最初は以下だけでも十分。

\conninfo     接続先確認
\l            DB一覧
\c DB名       DB切り替え
\dn           スキーマ一覧
\dt           テーブル一覧
\d テーブル   テーブル構造
\x            縦表示
\timing on    実行時間
\q            終了

SQL：

SELECT * FROM table LIMIT 10;

SELECT COUNT(*) FROM table;

BEGIN;

UPDATE ...;

DELETE ...;

COMMIT;

ROLLBACK;

特に本番環境では \conninfo → SELECT確認 → BEGIN → 変更 → SELECT確認 → COMMIT/ROLLBACK の流れを習慣にする。
