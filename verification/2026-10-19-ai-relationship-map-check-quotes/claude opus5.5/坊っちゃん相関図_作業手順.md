## 段階0 概略図(記憶ベース)

最初に、AIの知識だけで主要人物の図を作った。全体像をつかむには役立つが、**本文の裏付けがない**ことを前提に扱う。あとの段階で、この図にいくつも誤りや見落としがあったことがわかった。

形式: インラインのSVG図(おれを中心に、清・山嵐・うらなり・マドンナ・赤シャツ・野だいこ・狸・生徒たち)

## 段階1 本文を用意する

- 青空文庫の図書カードから「テキストファイル(ルビあり)」のzipを入手する。
- **つまずいた点**: 作業環境から青空文庫やGitHubのミラーへ直接ダウンロードできなかった。ページ読み取りツール経由では、長すぎて**第四章の途中までしか届かなかった**。
  - その時点で、確認できた範囲(第一〜四章)は実線、それ以降は記憶ベースの破線として図を描き分け、限界を明示した。
  - 最終的に、ユーザーがzipを添付して解決した。
- 教訓: **本文が全部読めているかを、最初に必ず確認する。** 読めた範囲をAI自身に申告させるとよい。

---

## 段階2 整形と章分割

- 文字コード: Shift_JIS → UTF-8 に変換する。
- 青空文庫の注記を除去する: ルビ `《…》`、ルビ開始記号 `｜`、入力者注 `［＃…］`、冒頭の記号説明、末尾の底本情報。
- 漢数字だけの行(一〜十一)を章見出しとして分割する。

```python
import re
t = open("raw.txt", encoding="utf-8").read().replace("\r", "")
t = t.split("-------------------------------------------------------", 2)[2]  # 冒頭の記号説明を除く
t = t.split("底本：")[0]                                                       # 末尾の底本情報を除く
t = re.sub(r"《[^》]*》", "", t).replace("｜", "")
t = re.sub(r"［＃[^］]*］", "", t)
parts = re.split(r"\n\s*([一二三四五六七八九十]+)\n", t)                        # 章見出しで分割
```

結果: 全11章、合計約9万字。

| 狸 | 校長 |
| 赤シャツ | 教頭、文学士 |
| マドンナ | 遠山のお嬢さん |

各人物には、別名・立場・初登場の章を付ける。端役(勘太郎、兼公と角、小使など)は「端役」として区別し、表示を切り替えられるようにした。

## 段階4 関係を根拠つきで抽出する

### プロンプトの型

```
以下の本文から登場人物間の関係を抽出してください。
出力はJSON配列で、各要素は {from, to, relation, chapter, evidence} とします。
evidenceには本文の該当箇所を短く引用してください。
本文に書かれていない関係は推測で追加しないでください。
関係が物語の途中で変化する場合は、変化前と変化後を別の要素にしてください。
本文が途中で切れている場合は、どの章まで読めたかを明記してください。
```

### ポイント

- **根拠(evidence)を必須にする。** もっともらしい関係のでっち上げを防げる。
- **変化する関係は別々に記録する。** 例: 山嵐とおれは「下宿を世話(第二章)→誤解・絶交(第六章)→和解(第九章)→共闘(第十章)」。
- 主人公以外の人物どうしの関係も明示的に求める(赤シャツと野だ、うらなりとマドンナなど)。

## 段階5 図を描く

- 人物と関係をデータ(配列)として持ち、描画と分ける。
- Cytoscape.js で描画。人物は役割で色分け(家族・東京/おれの味方/赤シャツ派/学校・中立/松山の町)。
- 機能:
  - 人物をタップすると、関係と根拠を章順に表示
  - **章スライダー**で「第N章の時点」の人物と関係だけを表示
  - 端役の表示切り替え

データと描画を分けておくと、絞り込みや修正が簡単になる。

## 段階6 根拠を機械的に照合する

抽出した引用が本文に実在するかを、スクリプトで全件確認する。あわせて、引用を含む**一文全体**を本文から切り出す。

```python
for a, b, label, ch, quote in relations:
    found = [c for c in chapters if quote in chapters[c]]
    print(a, b, label, "表示章", ch, "実在章", found or "本文で確認できない")
```

結果: 56件すべてが本文に実在した。

## 段階7 根拠の「質」を人間の目で確かめる

引用が実在しても、**その文が関係を本当に裏付けているとは限らない。** 一件ずつ読み直した。

### より適切な文に差し替えたもの(6件)

| 関係 | 理由 |
|---|---|
| 狸→おれ(上司) | 「校長室へ通した」では上司関係を示せない。辞令を渡す文に変更 |
| 山嵐→いか銀(下宿を周旋) | 申し出の文ではなく、実際に案内した文に変更 |
| 生徒→おれ(バッタ事件) | からかいの文だけだったので、第四章のバッタの文を追加 |
| 野だ→赤シャツ(腰巾着) | 主語の省略された短い文から、随行を書いた文に変更 |
| 山嵐→おれ(絶交) | 絶交そのものを書いた第八章の文を追加 |
| 赤シャツの弟→山嵐(誘い出す) | 喧嘩を知らせる文ではなく、誘いに来た文に変更 |

### 本文で確認できなかったもの(2件)

- 体操の教師と書記の川村が赤シャツに同調したこと(会議に出てくるが、意見は述べていない)
- 芸者「鈴ちゃん」と「小鈴」が同一人物であること(名前の一致からの推定)

### 伝聞・推測として区別したもの

- 萩野の婆さんの伝聞: うらなりとマドンナの婚約、赤シャツの横恋慕、山嵐と赤シャツの不仲、うらなりの母の頼み、延岡行きの経緯
- 作中人物の推測: 赤シャツの「策略」(おれと山嵐の見立て)、新聞記事の裏工作(山嵐の推測)
- 赤シャツの中傷は山嵐を名指ししておらず、おれがそう受け取ったもの
