明日使える生成AI ／ ブログのひみつ

このブログの専門担当は3人で、それぞれ名前があります。1人目、ネタ出し担当のヒラク。切り口を拓くからヒラクです。思いつきから、記事ネタの切り口を複数並べてくれます。どれにするかを選ぶのは人です。2人目、クラ。ネタ帳という蔵の番人で、足してよいかを審査します。、重複や、書けないネタを見つけます。落とすときも、代わりの置き場所を示します。3人目、アカネ。原稿に赤を入れる校閲担当で、書き上がった下書きをルールブックと照らして点検します。3人とも、点検して指摘するだけで、ファイルは書き換えません。直すのは、人とメインのAIの仕事です。
