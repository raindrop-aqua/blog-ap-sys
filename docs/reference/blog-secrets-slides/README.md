# ブログのひみつ解説スライド（発表用・24枚）

2026-11-07（土）の発表用に作ったスライド。聴衆は中学生にも伝わる言葉を想定している。発表時間は入れ替え込みで15分の枠なので、実質12〜13分。

- 公開先: https://claude.ai/artifact/EB9aGyySq11Xk8GAQ2GGda （Claudeのスライド Artifact。非公開なので、見せるには作成者が共有設定をする）
- 構成: 前振り（自己紹介・ブログ紹介）→ 表紙 → 今日の流れ → 4つのパート（各パートの先頭に扉）→ まとめ → QRコード
  - パート1 ブログのしくみ（ひみつ1〜4）
  - パート2 ルールブック＝`docs/planning` の3冊（ひみつ5〜8）
  - パート3 スキル（ひみつ9〜11）
  - パート4 エージェント（ひみつ12〜14）
- `project/deck.json` — スライドの順番・章立て・書体
- `project/slides/*.html` — 1枚1ファイル。発表者ノートは各ファイル末尾の `<aside>`
- `build.py` — 上の `project/` を書き出すスクリプト。内容を直すときはここを編集して再実行する
- `qr.svg` — ブログ（https://raindrop-aqua.github.io/blog-ap-sys/）のQRコード。`../blog-mechanism-slides-ai-focus/` のものを流用した

## 作り直し

```sh
python3 build.py
```

出力した `project/` を Artifact に上げ直すと反映される。ページ番号（「05 / 24」）は `build.py` が枚数から振るので、枚数を変えたら全スライドを上げ直す。

数字（ネタ帳「54本」は2026-09-20時点）や、スキル・エージェントの構成が変わったときは、`.claude/` の中身と合わせて直す。
