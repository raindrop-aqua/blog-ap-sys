公開されるものと、されないもの

site/

Jekyll が材料にする場所

ここだけが材料

_posts/

完成した記事

公開される

_drafts/

書きかけの記事

出ない

assets/

記事の画像など

公開される

docs/

企画メモ・ルールブック

出ない

verification/

数字を確かめた生データ

出ない

CLAUDE.md

AIに読ませる説明書

出ない

許可する範囲を、1つだけ決める

「これは出さない」という禁止リストではなく、「site/ の中だけを材料にする」と決めている。

書き忘れが起きないので、うっかり公開の事故を、しくみで防げる。

明日使える生成AI ／ ブログのしくみ

07 / 23

このプロジェクトには、記事以外にも企画メモやAI向けの説明書が入っています。これがうっかりネットに出たら困ります。そこで、『これは出さない』という禁止リストを作るのではなく、『siteフォルダの中だけを材料にする』と、許可する範囲を1つだけ決めています。リストへの書き忘れが起きないので、事故がしくみで防げます。ちなみに、書きかけの記事を入れるdraftsフォルダは、本番のビルドには入りません。
