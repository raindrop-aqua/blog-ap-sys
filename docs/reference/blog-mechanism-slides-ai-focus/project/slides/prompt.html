17 / 40

AIに出す指示のことをプロンプトといいます。AIは次のことばを予想する機械なので、指示がうすいと、ふつうの文章を予想するしかありません。だれに向けて、どのくらいの長さで、何を入れて、と条件を足すほど、次のことばの候補がしぼられて、ねらった文章に近づきます。このブログにはプロンプト設計というカテゴリーがあって、この書き方を扱っています。
