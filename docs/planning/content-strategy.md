# コンテンツ戦略設計書

「明日使える生成AI」のブログ運営方針をまとめた設計書。今後の記事執筆・シリーズ企画・投稿計画の拠り所とする。

- 関連ドキュメント: なし（本ドキュメントが起点）
- ステータス: ドラフト（v0.1）

---

## 1. ブログコンセプト

- **サイト名**: 明日使える生成AI
- **一言コンセプト**: 「明日の仕事で、そのまま使える」生成AIの小技・プロンプト・活用事例を届ける
- **差別化ポイント**:
  - 生成AIの一般ニュース・新機能解説ではなく、**業務に持ち帰れる具体的な使い方**に絞る
  - 理論より実例。プロンプトの実物、Before/After、手順のスクショを重視
  - ChatGPT / Claude / Copilot など**複数ツールを横断**し、ツールごとの向き不向きも扱う

## 2. 対象読者（ペルソナ）

| 項目 | 内容 |
|---|---|
| メイン読者 | 生成AIを業務で使い始めた・使おうとしている会社員（非エンジニア中心） |
| リテラシー | ChatGPTは触ったことがあるが、プロンプトの工夫や使い分けまでは詳しくない層 |
| 抱えている課題 | 「便利そうだが自分の業務にどう活かせばいいかわからない」「毎回微妙な回答しか返ってこない」 |
| 読む場面 | 仕事の合間・昼休みなどにスマホで検索 → 該当記事だけ読んで即実践 |
| 検索意図の例 | 「ChatGPT 議事録 プロンプト」「Claude Excel 使い方」「生成AI 資料作成 コツ」 |

サブ読者として、社内でAI活用を広めたい情報システム・企画部門の担当者も想定する（社内共有しやすい記事構成にする）。

## 3. 記事シリーズ設計

大カテゴリ（`categories`）を軸に、シリーズとして積み上げていく。カテゴリはURLパスに反映されるため、最初に体系を決めておく。

| カテゴリ | 内容 | 記事イメージ |
|---|---|---|
| `プロンプト設計` | 汎用的に効くプロンプトの型・コツ | 「箇条書き→企画書に整えるプロンプト」「役割設定で回答精度を上げる」 |
| `業務効率化` | 職種横断で使える業務シーン別の活用事例 | 「議事録作成」「メール下書き」「資料要約」 |
| `ツール比較` | ChatGPT / Claude / Copilot など横並び比較・使い分け | 「長文要約はどれが強い？」「Excel作業ならこれ」 |
| `Tips・小技` | 単発の小ネタ、時短テクニック | 「ショートカット」「拡張機能」「小ネタ集」 |
| `お知らせ` | ブログ運営に関する告知（既存カテゴリ、継続使用） | 開設記事など |

- 各記事には `tags` で横断キーワード（ツール名・職種・シーン等）を付与し、関連記事の回遊を作る
- カテゴリが増えすぎないよう、当面はこの5分類で運用し、記事が溜まってから見直す

### シリーズ企画例（今後のネタ帳）

1. プロンプト設計の型シリーズ（全5回想定）: 要約 / 企画書化 / 添削 / 壁打ち / 役割設定
2. 業務別活用事例シリーズ: 議事録・メール・資料作成・データ集計・企画立案
3. ツール使い分けシリーズ: ChatGPT vs Claude vs Copilot を用途別に比較

## 4. 投稿戦略

- **頻度**: 週1本を目標（無理せず継続を優先。溜まったら週2本に増やす）
- **曜日**: 月曜投稿を基本とし、週明けの業務にすぐ使える形で届ける
- **1本あたりの分量**: 3〜5分で読める長さ（見出し3〜4個、具体例を必ず1つ以上）
- **ネタの選び方**: 実際に自分が業務で使って効果があったものを優先し、机上の想像で書かない
- **シリーズの組み方**: 単発Tipsと、複数回に渡るシリーズ記事を交互に配置し、飽きさせない
- **導線設計**:
  - 各記事末尾に関連カテゴリ・関連記事へのリンクを置く
  - シリーズ記事は次回予告を末尾に添える

## 5. 記事フォーマット（型）

```markdown
---
layout: post
title: "記事タイトル（検索されそうな言葉を含める）"
date: YYYY-MM-DD
categories: [カテゴリ名]
tags: [ツール名, 職種/シーン, キーワード]
---

## この記事でわかること（結論を先出し）

## 使うシーン

## 実際のプロンプト・手順

## Before / After（できれば）

## まとめ
```

- タイトルは検索キーワードを意識しつつ、「明日使える」感（具体性・即効性）を出す
- 冒頭で「誰の・どんな悩みを解決する記事か」を1〜2文で明示する
