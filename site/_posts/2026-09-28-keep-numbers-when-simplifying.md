PDFを要約させたら、数字が変わっていた。そういう経験がある方に向けて、指示に足す一言を試しました（[先日の「小学生でもわかるように」記事]({{ site.baseurl }}/posts/summarize-reader-level-purpose/)の追加検証記事です）。

## 結論

足した一言は、これです。

```
数字は、元の論文の表記のまま残してください。
```

筆者が試した範囲では、一言を足すと数字は消えにくくなりました。ただし、崩れが減るとは言い切れません。だから、一言を足すかどうかに関わらず、数字は原本で確かめます。

手で描く絵の「増えた38パーセント、減った29パーセント」は、一言を足さなかった6回では1回も出ませんでした。足した6回では5回出ました（残る1回は、その話題に触れていません）。

崩れは、足さなくても毎回は起きませんでした。「2〜3割」を「2〜3人に1人」と書き換える崩れは、足さなかった6回のうち1回、足した6回では0回です。この差は、1回ごとの出力の揺れと区別できません。

足した6回では、突き合わせた範囲では食い違いは見つかりませんでした。それでも数字の照合は省けません。足さなかった6回でも、食い違いは1回だけでした。足した6回で0回でも、崩れが消えたとは言えないからです。

## 手順

素材は、[前回の記事]({{ site.baseurl }}/posts/summarize-reader-level-purpose/)と同じ論文です。GLOCOM Discussion Paper 24-001「画像生成AIについてのクリエイターの賛否は割れている」（2024年4月、全21ページ）で、[公開されています](https://www.glocom.ac.jp/wp-content/uploads/2024/04/GLOCOM_DISCUSSIONPAPER_No.24_2024-001-1.pdf)。ツールはClaude Sonnet 5で、2026年9月20日に、PDFを添付して12回投げました。業務の資料は使っていないので、同じ論文を使えば手元で再現できます。

前回、数字が食い違ったのは幼稚園児向け、丸められたのは小学生向けでした。そこで、この2つを、次の2通りで各3回ずつ投げました。

```
添付のPDFの内容を、【幼稚園児】でもわかるように説明してください。
```

```
添付のPDFの内容を、【幼稚園児】でもわかるように説明してください。
数字は、元の論文の表記のまま残してください。
```

【幼稚園児】は【小学生】にも替えました。

手順は次のとおりです。

1. 指示の最後に、上の一言を足す
2. 新規チャットで2〜3回投げる。1回の出力では、崩れたのか揺れたのか分かりません
3. 出力の数字を拾い、原本のPDFで検索して照合する。特に、割合を「N割」「N人に1人」と言い換えた箇所を見る。「2〜3割」は10人に2〜3人で、「2〜3人に1人」なら33〜50パーセントになります
4. 数字の話題が丸ごと無いときも、原本で探す。崩れではなく、消えている場合があります

12回の結果は、次のとおりです。

| | 足さない（6回） | 足す（6回） |
|---|---|---|
| 「2〜3割」の崩れ | 1回 | 0回 |
| 手描きの増38%・減29%が数字で出た | 0回 | 5回 |
| 小学生向けの文字数（3回の範囲） | 857〜1,105字 | 1,412〜1,620字 |

同じ指示でも、出力の形は揃いませんでした。幼稚園児向けの漢字は、29字のものと202字のものがあります。ほぼひらがなだけの出力は、幼稚園児向け6回のうち3回で、一言を足した回にも足さなかった回にも出ました。

（お恥ずかしい話ですが）自分の数字への適応能力が不足しているせいかもしれませんが、筆者は、数字が入っていない出力のほうがしっくりきました。要約と正確さは、両立するのが難しいと感じました。数字を残すと、小学生向け3回の平均は985字から1,533字に伸びました（記号と改行を含む字数です）。

使い分けとしては、全体を掴むだけなら、一言は足さなくても構いません。数字を誰かに伝えるときや、判断に使うときは、原本で必ず確かめます。

## 補足

今回確かめたのは、Claude Sonnet 5、1本の論文、幼稚園児向けと小学生向け、各3回です。ChatGPT・Gemini・Copilotでは試していません。回数を増やせば、「2〜3割」の崩れに差が出るのかは、分かりません。

照合は、Claude Codeが、論文のPDFから取り出したテキストと出力を突き合わせました。筆者が図表を1つずつ目で追ったわけではありません。

前回の記事では、数字の食い違いと丸めを1つずつ挙げました。足さなかった6回のうち、幼稚園児向けの1回で「2〜3人に1人」が再現しました。足さなかった6回では、手で描く絵の増減を「同じくらい」と書いた出力は出ませんでした。論文の本文は、この増減を「拮抗しており、むしろ増えたの方がやや多い」と書いています。
